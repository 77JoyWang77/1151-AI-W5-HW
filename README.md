# 🐟 電子木魚・功德無量

敲木魚累積功德的療癒小網頁，順便替考試、報告祈福。

- **技術**：單一 `index.html`（原生 HTML / CSS / JavaScript），不需要外部圖片或音檔
- **部署**：GitHub Pages

## 規格書

### 1. 專案概述
| 項目 | 內容 |
|------|------|
| 名稱 | 電子木魚・功德無量 |
| 目標使用者 | 壓力大、需要放空一下的學生 |
| 技術限制 | 單一 `index.html`，音效用 Web Audio API 即時合成，圖形用 inline SVG |

### 2. 功能清單
| 優先級 | 功能 | 說明 |
|--------|------|------|
| P0 | 敲擊木魚 | 點擊木魚、觸控或按空白鍵都能敲 |
| P0 | 「XX +1」浮字 | 每敲一下就飄出祈願文字 +1，往上淡出 |
| P0 | 敲擊動畫 | 木魚擠壓回彈；木槌沒在敲時保持待機輕晃，敲擊時往下砸再回彈 |
| P0 | 敲擊音效 | Web Audio API 即時合成，三種風格音色各不相同 |
| P0 | 功德計數 | 顯示總功德與今日功德（換日自動歸零） |
| P0 | 資料保存 | localStorage 保存，重新整理後紀錄仍在 |
| P1 | 風格切換 | 🪷 禪意古風／🌃 賽博佛祖／🐣 可愛 Q 版，配色、字體、木魚外觀、音效都會改變 |
| P1 | 連擊 Combo | 1 秒內連續敲擊會累積：≥10 字體放大、≥30 噴出粒子、≥60 COMBO 文字脈動 |
| P1 | 祈願文字 | 7 個預設選項，也可以自訂（最多 12 字） |
| P1 | 成就系統 | 7 個成就，解鎖時跳出通知，並可查看成就列表 |
| P1 | 靜音開關 | 一鍵切換 🔊／🔇 |
| P2 | 自動敲擊 | 功德達 500 解鎖，每秒自動敲一下 |
| P2 | 重置功德 | 跳出確認視窗「確定要散盡功德嗎？」 |

### 3. 祈願預設選項
功德、考試 all pass、程式一次跑過、報告順利完成、早八不遲到、錢包變厚、好運連連、✏️ 自訂

### 4. 成就列表
| 成就 | 條件 |
|------|------|
| 🔔 第一聲木魚 | 敲下第一下 |
| 🌱 初入佛門 | 累積 10 功德 |
| 📿 小有功德 | 累積 100 功德 |
| 🪷 功德深厚 | 累積 500 功德（解鎖自動敲擊） |
| 🧘 得道高僧 | 累積 1,000 功德 |
| ✨ 功德圓滿 | 累積 9,999 功德 |
| ⚡ 手速如來 | 單次連擊達到 50 |

### 5. 操作流程
1. 開啟網頁，看到木魚和功德計數器
2. 點擊木魚或按空白鍵 → 音效、動畫、浮字同時出現，功德 +1
3. 快速連敲 → 出現 COMBO，特效逐級升級
4. 達到門檻 → 上方跳出成就通知
5. 切換祈願或風格 → 浮字文字或整體外觀立即改變
6. 關閉後重新開啟 → 功德、成就、設定都保留

### 6. 畫面配置
```
┌───────────────────────────────┐
│ 功德無量             🔊  🏆    │  標題、靜音、成就
│ [ 總功德 ]   [ 今日功德 ]       │
│          XX +1 ↑              │  浮字
│       🔨  ( 木魚 )             │  主體
│         COMBO x12             │
│ 祈願 [ 考試 all pass ▼ ]        │
│ 風格 [禪意][賽博][可愛]          │
│ 掛機 [ 🔒 自動敲擊 ]            │
│        散盡功德（重置）           │
└───────────────────────────────┘
```
支援 RWD，手機直式也能正常操作。

### 7. 資料儲存（localStorage key：`muyu-save`）
| 欄位 | 內容 |
|------|------|
| `total` / `today` / `date` | 總功德、今日功德、日期（用來判斷換日） |
| `wish` / `customWish` | 目前祈願、自訂文字 |
| `achievements` / `bestCombo` | 已解鎖成就、最高連擊 |
| `theme` / `muted` / `auto` | 風格、靜音、自動敲擊 |
